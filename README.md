# Personal website

A plain HTML/CSS site. It needs no build step or frameworks.

- `index.html` holds the content.
- `style.css` holds the colors, fonts and layout. Change the variables at the top to restyle the whole site.

## Editing

Every yellow-highlighted piece of text is a placeholder. In `index.html` these sit inside `<span class="todo">…</span>`.
Replace the text, then delete the `<span class="todo">` wrapper around it.

To add a photo, save it as `photo.jpg` in this folder and follow the comment above the `SA` circle in `index.html`.
To add your CV, save it as `cv.pdf` in this folder.

## Preview

Open `index.html` in any browser.

## Publish on GitHub Pages (free)

1. Create a public GitHub repository named `<your-github-username>.github.io`.
2. Upload these files to the repository.
3. The site goes live at `https://<your-github-username>.github.io` within a minute or two.
